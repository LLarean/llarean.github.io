Custom themes for [GitExtensions](https://github.com/gitextensions/gitextensions), based on the [ppy JetBrains theme](https://github.com/peppy/ppy-jetbrains-theme) by Dean Herbert. Refined for Windows 11 — layered surfaces, softer borders, better contrast.

| Файл | Описание |
|------|----------|
| `ppy-dark.css` | Dark — purple-tinted layered surfaces, Win11 depth system |
| `ppy-light.css` | Light — neutral grey layered surfaces, improved contrast |

## Установка

1. Скопируйте `.css` файл(ы) в `%AppData%\GitExtensions\GitExtensions\Themes\`
2. Перезапустите GitExtensions
3. Перейдите в **Settings → Appearance → Color theme** и выберите тему
