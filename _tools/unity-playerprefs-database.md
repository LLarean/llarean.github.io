A minimal save system for small-to-medium Unity games that don't need a full database but want more structure than raw PlayerPrefs key strings.

**PlayerPrefsDatabase** stores data as JSON under a single PlayerPrefs key per "table", giving you typed read/write operations without external dependencies. Suitable for save data, settings, and player progress in mobile and casual games.
