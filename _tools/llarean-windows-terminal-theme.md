Custom color scheme for [Windows Terminal](https://github.com/microsoft/terminal).

## Установка

1. Установите [Cascadia Mono NF](https://github.com/microsoft/cascadia-code/releases), если ещё не установлен.
2. Скопируйте содержимое `settings.json` в настройки Windows Terminal или замените файл по пути:
   ```
   %LOCALAPPDATA%\Packages\Microsoft.WindowsTerminal_8wekyb3d8bbwe\LocalState\settings.json
   ```
